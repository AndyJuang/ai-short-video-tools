# applemint-marketplace

Claude Code plugins from applemint.

| Plugin | What it does |
|---|---|
| [ad-video-tools](plugins/ad-video-tools) | Rebuild an ad in an existing video's exact layout with your footage, copy, language and brand, or cut a short from a plan and a folder of raw footage. |

## Install

```
/plugin marketplace add applemint-ltd/applemint-marketplace
/plugin install ad-video-tools@applemint-marketplace
```
